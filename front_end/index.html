About The Project Workflow

How our computer vision pipeline transforms raw road surface photographs into actionable infrastructure intelligence.

01

Image Upload

User uploads a high-resolution photograph of the road surface captured via smartphone, mobile camera, or drone camera.

02

Preprocessing

Image is resized (e.g. 224x224 RGB), normalized in tensor scale [0,1], and adjusted for optimum lighting and contrast balance.

03

CNN Feature Extractor

Deep Convolutional layers scan image features using kernels to extract edge patterns, surface textures, and structural shapes.

04

Classification Result

Dense Softmax layer computes exact probabilities for Crack, Manhole, and Pothole, displaying confidence metrics.

Target Road Feature Classes

1. Crack

Surface Fissure

Linear or block fracture patterns on asphalt or concrete pavement caused by moisture intrusion, temperature fluctuation, heavy axle loads, or aging binder material.

  • Longitudinal & Transverse cracking
  • Early indicator of structural degradation
  • Preventative sealing recommended

2. Manhole

Utility Fixture

Utility access covers integrated into the road surface. Classified to distinguish standard municipal infrastructure covers from hazardous road damage or uneven rim heights.

  • Circular or rectangular iron frames
  • Normal road infrastructure object
  • Monitors rim alignment elevation

3. Pothole

Critical Hazard

Bowl-shaped depressions in road pavement resulting from water weakening the soil subbase under traffic forces, leaving hollow pockets that collapse.

  • Severe hazard to tires and suspension
  • Requires immediate cold/hot asphalt patch
  • High priority maintenance alert
Deep Learning Fundamentals

CNN Model Mechanics

Understanding how Convolutional Neural Networks process visual inputs layer-by-layer to detect road damage.

Layer 1

1. Convolution (Kernel Filters)

Small matrices called kernels or filters slide across the input image pixels. Performing element-wise multiplication extracts mathematical feature maps representing sharp edges, asphalt textures, and cracks.

Feature Map Generation
Layer 2

2. Pooling (Dimensionality Reduction)

Max Pooling reduces spatial dimensions (width and height) of feature maps while retaining dominant features. This reduces computation cost, speeds up training, and achieves spatial translation invariance.

Max Pooling 2x2
Layer 3

3. Hierarchical Feature Extraction

Deep stacked layers build a hierarchy: early layers learn low-level primitives (lines, curves), middle layers combine them into shapes (fissure lines, rim circles), and deeper layers recognize complex road defect structures.

Deep Representations
Layer 4

4. Fully Connected & Softmax

Extracted 2D feature maps are flattened into a 1D vector and passed to Dense layers. The final Softmax activation function outputs a normalized probability distribution summing to 1.0 (100%) across Crack, Manhole, and Pothole.

Backend Connection Guide

Connect your trained TensorFlow/Keras Python model in seconds via Flask or FastAPI.

How To Connect Your Python Model

The frontend is decoupled and ready for production API endpoints. Currently, it runs in Mock Mode. To connect your custom trained `.h5` or `.keras` model:

  1. Step 1: Run your Python backend (flask_app.py or fastapi_app.py provided in the codebase).
  2. Step 2: Open js/api.js in your project.
  3. Step 3: Change USE_MOCK: true to false:
js/api.js Configuration
const API_CONFIG = {
    // Set to false to send requests to Python Backend
    USE_MOCK: false,
    API_URL: 'http://127.0.0.1:5000/predict'
};
backend_examples/flask_app.py Python Backend Reference 
from flask import Flask, request, jsonify
from flask_cors import CORS
import tensorflow as tf
import numpy as np
from PIL import Image

app = Flask(__name__)
CORS(app) # Enable CORS for frontend requests

# Load your trained CNN model
model = tf.keras.models.load_model('road_damage_cnn.h5')
CLASSES = ['Crack', 'Manhole', 'Pothole']

@app.route('/predict', methods=['POST'])
def predict():
    file = request.files['image']
    img = Image.open(file.stream).convert('RGB').resize((224, 224))
    img_array = np.array(img) / 255.0
    img_tensor = np.expand_dims(img_array, axis=0)
    
    preds = model.predict(img_tensor)[0]
    top_idx = int(np.argmax(preds))
    
    return jsonify({
        'class': CLASSES[top_idx],
        'confidence': float(preds[top_idx]),
        'probabilities': {
            'Crack': float(preds[0]),
            'Manhole': float(preds[1]),
            'Pothole': float(preds[2])
        }
    })

if __name__ == '__main__':
    app.run(port=5000, debug=True)
